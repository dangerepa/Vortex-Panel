FirstOrderVortexPanelMethod.m and SecondOrderVortexPanelMethod.m run on their own as long as generate_naca4.m is in the path. 
For the unsteady panel method, all files must be installed in the same path, along with generate_naca_4.m, and main_unsteady.m should be run.

Parameters to change are at the top of the respective codes.
